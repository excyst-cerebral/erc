# Manuscript figure design

The final figures are original TikZ/PGFPlots vector graphics generated directly
from the released aggregate JSON files. No experimental values are changed.

Run `python report/plots.py`, `python report/auditfig.py`, `python report/workflowfig.py`, then
`python report/checkpgf.py`.
Requirements: Python/NumPy, pdfLaTeX with PGFPlots, TikZ, standalone and Latin
Modern, plus Poppler (`pdftoppm`, `pdftotext`, `pdffonts`). TeX binaries must be on
PATH. Generated standalone TeX sources are in `figures/pgf/`, final PDFs and PNG
previews in `figures/`, and plotted values in `figures/pgf_data_manifest.json`.
The manuscript source package also includes the standalone sources.

Figures use a 6.5-inch canvas, 9.5 pt labels and 10 pt panel headings. The narrower
author manuscript scales them slightly. Navy (#1F5A85) emphasizes the exact
method; muted teal, rust, purple, slate and charcoal distinguish comparisons.
Markers and line patterns redundantly encode methods for grayscale reading.
Grid lines are light and legends sit outside the data panels. Error bars show
SD across seeds, except the runtime figure, which shows the minimum–maximum
range around the median of five paired measurements. The primary audit plot uses alpha=0.09, gamma=0.01 and r=200. The frontier
shows each fixed allocation separately. The audit plot displays all 30
seeds with deterministic horizontal jitter; black diamonds and bars show mean
and sample SD. Jitter does not change measured values.

The diagnostic recall panel has an explicitly disclosed zoomed coverage axis.
The count-attainment bars start at zero. Runtime axes are logarithmic and compare the sweep with direct greedy binary search on the same instances. Coincident result curves remain
coincident; the captions explain them. These choices preserve limitations and
negative findings rather than implying an advantage unsupported by the data.

Design references supplied by the author:
- https://github.com/HarisIqbal88/PlotNeuralNet
- https://tikz.net/tag/neural-networks/
- https://tikz.net/category/computing/machine-learning/
- https://f0nzie.github.io/tikz_favorites/

These informed the LaTeX-native typography and diagram alignment. No diagram
code or illustration from those collections is copied. The method overview
illustrates this paper's calibration rule, rather than a neural architecture.

`report/mplfig.py`, `report/solverfig.py` and
`report/checklayout.py` retain the earlier Matplotlib workflow. They can
replace some final figure PDFs; run `report/plots.py` followed by `report/auditfig.py` and `report/workflowfig.py` to restore the
submission design. `report/checkpgf.py` only inspects outputs. Automated bounds
checks supplement visual review; they do not certify all possible collisions.

The direct runtime plot compares identical instances across the two-selection, greedy-search and sweep implementations. The targeted-review plot includes the existing pessimistic partial-label rule and the fixed-cost clean audit, so a gain over the coarse baseline is not presented as a new statistical advantage.

The adaptive-review frontier is regenerated by `report/allocfig.py`.
Its four panels retain all six fixed review costs and all six displayed method
comparisons. The ten-class and binary rows use separate labeled vertical scales.
Points and bars show means and sample SD over 30 paired seeds; the CSV summary
also records coverage. Source values are saved in `review_allocation_values.json`.
